# lagos-pharma-distribution-optimisation

Key findings
• The lowest-cost weekly plan costs ₦92,800, confirmed independently in Python and Excel.
• The network has only 40 cartons of spare stock. If Apapa's stock falls below 210 cartons, demand cannot be met at all.
• A disruption on the Apapa→Lekki route is the costliest scenario tested (+₦2,900 a week, +3.1%), while closing Apapa→Surulere costs only +₦800 (+0.9%).
